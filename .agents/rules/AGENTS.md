# GameCreateTeam プロジェクト共通ルール (AGENTS.md)

このリポジトリは、AIゲーム制作チーム（**GameCreateTeam**）が自律的にモバイルファーストのWebゲームを企画・設計・製造・テスト・リリースするプラットフォーム **「AI Game Lab」** です。

## 0. 最重要コンセプト：「1日で飽きられてもいい！X（SNS）で話題になるゲームを作る」

- **長寿な優等生ゲームより「瞬間最大風速（SNSバズ）」を最優先する**:
  - 半年遊ばれる真面目なゲームではなく、**「1日で飽きられてもいいから、X（旧Twitter）で『なにこれwww』『ムズすぎて草』『結果がひどいwww』と拡散・ツッコミされるゲーム」** を作ってください。
- **SNSバイラル必須3原則**:
  1. **出オチ感・1秒で刺さる強烈なフック**: タイトルと画面を見た瞬間に笑える・ツッコミたくなるシュールな題材や、クセになる一発ネタ・バカゲー・激ムズアクション・診断系要素を取り入れること。
  2. **1プレイ15秒〜90秒の超高速ループ**: 説明不要で始まり、あっけなく（または劇的に）終わって「もう1回！」と連打してしまうテンポ感。
  3. **スクショ映えするリザルト ＆ 「𝕏 でシェア」ボタンの標準搭載**:
     - ゲーム終了画面には単なるスコアだけでなく、思わずSNSに貼りたくなる **「パワーワードな称号・死因・煽り/褒め寸評」** を必ず表示すること。
     - リザルト画面には必ず **「𝕏（旧Twitter）で結果をシェア」ボタン**（`https://twitter.com/intent/tweet?text=...&url=...` を新しいタブで開くボタン）を実装すること。

## 1. プラットフォーム技術仕様・制約

- **フレームワーク**: Vite + React 18 + TypeScript + Tailwind CSS v4 + Lucide Icons
- **モバイルファースト画面枠**:
  - ゲームプレイ画面（`src/pages/GamePlayPage.tsx`）は、スマートフォンではフル画面（`100dvh`）、PCでは中央固定の**スマホ縦画面フレーム（最大幅 `430px`）**内で動作します。
  - 各ゲームコンポーネント（`src/games/<game-id>/index.tsx`）は、共通スリムヘッダーを除いた残り領域（`h-full w-full`）の中に収まるように設計・実装してください。
  - **横スクロールのはみ出し厳禁**: `375px〜430px` 幅のスマホ縦画面で要素が横にはみ出さないこと。
- **コード分割（遅延読み込み）**:
  - すべてのゲームは `src/games/<game-id>/index.tsx` に `export default` で実装し、`src/games/registry.ts` の `GAME_REGISTRY` に `React.lazy(() => import('./<game-id>'))` で登録します。
- **デザインテイスト**:
  - プラットフォーム全体は「カジュアル・ポップ風（明るい背景＋カラフルなアクセント、Nintendo Switchやカジュアルアプリのような親しみやすいUI）」で統一します。

## 2. ドキュメント・記録のルール

- **リポジトリ内に企画書や議事録のMarkdownファイルを残さないこと**。
- なぜそのゲームを作ることになったかの候補比較（ジャンル選定理由）・市場調査・企画会議（4人の議論ログ）・要件定義・基本設計・レビュー記録はすべて **対象の GitHub Issue のコメント欄（および本文）** に投稿して記録します。

## 3. 品質・エラーゼロの絶対原則 ＆ PR承認・マージ権限ルール

- **Pull Request の勝手なマージ厳禁（ユーザー承認必須）**:
  - AIエージェントが行ってよいのは **Pull Request の作成（`create-pr`）まで** です。
  - **Pull Request の承認・マージは必ずユーザー（人間）が行います**。AIエージェントが自ら API やコマンドで PR をマージすること、および `main` ブランチへ直接ゲーム変更を push することは一切厳禁です。
- 以下の検証をすべてパスしない限り、PR作成や完了報告を行うことは厳禁です：
  1. `npm run lint`（TypeScriptの型エラー0件）
  2. `npm run test`（Vitestによるゲームロジックの単体テスト＋レジストリ整合性テスト全通過）
  3. `npm run build`（Vite本番ビルド成功）
  4. `npm run test:e2e`（Playwrightによるモバイル実ブラウザ起動・コンソールエラー0件・画面はみ出しなし検証）
- ゲーム制作の依頼（GitHub Issueの指定、または新規お題の提示、定期実行）を受けた場合は、必ず `.agents/skills/game-create-team/SKILL.md` スキルを起動し、AI社員7名のチーム体制で進めてください。
