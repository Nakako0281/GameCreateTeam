# リトライ性（Replayability）設計ガイド

GameCreateTeam (GCT) が目指すのは、瞬間的にバズって1回で飽きられる出落ちゲームではなく、**「何度も繰り返し遊べる（リトライ性の高い）ゲーム」** です。
1プレイが1分で終わる高速ループのゲームでも、1時間かけてじっくり構築するゲームでも構いません。最も重要なのは **「終わった瞬間に『次はあの戦略・ビルドを試したい』『次はもっと上手く立ち回れる』ともう1回プレイしたくなる構造」** です。

---

## 1. 何度も遊べるゲームが持つ「4つの柱」

企画を立案・審査する際は、必ず以下の4つがシステムとして組み込まれているかを確認します。

1. **毎プレイの変化（Input & Situation Variety）**
   - 初期配置、ツモ、出現する敵・イベント、ショップの品揃え、地形などがシード乱数によって毎回変化し、「前回と全く同じ手順」が通用しないこと。
2. **意味のある選択と戦略・ビルドの幅（Meaningful Choices & Synergies）**
   - プレイヤーに毎回悩ましい選択（「目の前の安定を取るか、将来のシナジーに投資するか」「どの系統に特化するか」）があり、**複数の異なる勝ち筋・プレイスタイル** が成立すること。
3. **実力・思考の介入と上達実感（Player Agency & Mastery）**
   - 運だけで決まらず、盤面の読み・リソース管理・操作精度・シナジー理解が深まるほど明確にスコアや到達度が伸びること。
4. **納得感のある敗北と「次への仮説」（Fair Failure & "Next Run" Hook）**
   - 負けた（またはスコアが伸び悩んだ）ときに「理不尽だった」ではなく、「あそこで欲張りすぎた」「次はあの組み合わせを試そう」と敗因と改善策がプレイヤー自身に分かること。

---

## 2. リトライ性の高いゲームの5大アーキタイプ（型）

市場調査や企画出しでは、以下のアーキタイプ（またはその掛け合わせ）をベースに、モバイル縦画面（`375〜430px`）で快適に遊べるシステムを設計します。

| 型 | 構造・特徴 | 想定1プレイ時間の目安 | リトライ性の源泉 |
| :--- | :--- | :--- | :--- |
| **A. シナジー＆ビルド構築型**<br>*(Roguelite / Deck / Inventory)* | 毎ウェーブ・毎ターン提示される要素（スキル・カード・遺物・配置）を組み合わせ、相乗効果（シナジー）で突破する | **10〜60分**<br>*(中断セーブ必須)* | 「今回は毒×連鎖ビルド、次はクリティカル特化を試そう」というビルド開拓欲 |
| **B. 戦術パズル・ボード戦略型**<br>*(Tactical Puzzle / Tile / Grid)* | 限られた盤面とリソースの中で、ランダムに供給されるピースや状況を最適配置・連鎖させてハイスコアや長期生存を狙う | **5〜30分**<br>*(中断セーブ推奨)* | 盤面整理の気持ちよさと、「あと1手こう置けば大連鎖だった」という悔しさ |
| **C. 物理・創発スコアアタック型**<br>*(Emergent Physics / Merge / Pinball)* | 物理挙動や合体・反射ルールと強化選択が絡み合い、予測不能かつ爽快な連鎖・インフレを生む | **2〜15分** | 物理の偶発的なドラマと、狙い通りに大連鎖が起きたときの脳汁体験 |
| **D. ハイスピード・リスク管理型**<br>*(Fast Action / Push-Your-Luck)* | 短時間に「どこまで欲張るか・どのルートを取るか」の判断が凝縮された高速ループ | **1〜5分** | 1プレイの軽快さと、明確なスキル上達・ハイスコア更新の中毒性 |
| **E. 経営・育成・防衛ストラテジー型**<br>*(Tower Defense / Economy / Sim)* | 限られた資金・時間をどこに投資して生産・防衛ラインを築くかを競う | **15〜60分**<br>*(中断セーブ必須)* | 投資順序・配置の最適化研究と、難関ウェーブを突破したときの達成感 |

---

## 3. プレイ時間の設計方針（1分〜1時間以上まで柔軟に設定）

1ゲームのプレイ時間に固定の制限はありません。**「そのゲームのコアループが最も面白くなる時間」** を企画段階で相談・決定し、企画書（MD）に理由とともに明記します。

### 短時間ループ型（1プレイ 1〜5分）の場合
- **リトライの即時性**: ゲームオーバーから0.5秒・1タップで次のランに入れるテンポを最優先する。
- **密度の設計**: 開始10秒目から意味のある判断が始まり、ダレる時間を作らない。

### 中〜長時間ラン型（1プレイ 5〜60分以上）の場合
- **ペーシング（序盤・中盤・終盤の展開変化）**:
  - **序盤**: 方針決定のきっかけとなる初期選択・コア要素の獲得。
  - **中盤**: シナジーの形成と、中ボスや難局によるビルドテスト。
  - **終盤**: 完成したビルドが気持ちよく回る爽快感と、最終試練（およびクリア後のエンドレス/高難度モード）。
- **中断・再開セーブ（`localStorage`）の必須化**:
  - モバイルブラウザで途中で閉じても、次回アクセス時に「続きから再開（Continue）」できるオートセーブ機能を必ず実装する。

## 4. 禁止アンチパターン（リトライ性を損なう要素）

企画レビュー（`03_critic_reviewer`）では、以下のアンチパターンが含まれていないかを厳しくチェックします。

1. **一発ネタ・出落ち感**:
   - タイトルのダジャレや1回のびっくり演出だけで、ゲームのシステム自体に2回目を遊ぶ深みがないもの。
2. **単一最適解（1強ビルド・思考停止の定石）**:
   - 特定の選択肢だけを選んでいれば簡単に勝てる、または同じ操作の繰り返しで永久に続くバランス崩壊。
3. **プレイヤーの選択が意味を持たない一本道 / 運ゲー**:
   - 何を選んでも結果が同じ、あるいは見えている情報からリスクを予測できず乱数だけで理不尽に即死するもの。
4. **モバイル縦画面での過度な煩雑さ**:
   - 極小ボタンの密集、スクロールしないと見えない重要情報、長文テキストを読ませないと判断できないUI。

## 5. 企画選定・社内レビュー評価軸（30点満点）

人間（最高責任者）へ企画書を提出する前に、AIチーム内で以下の6軸（各5点）で評価・ブラッシュアップを行います。

| 評価軸 | 5点（合格基準） | 1点（却下基準） |
| :--- | :--- | :--- |
| **1. リトライの引力** | 1プレイ終了時に「次はあの方針でやりたい」と自然に思える構造がある | 1回クリア/失敗したら満足して閉じる |
| **2. 選択とビルドの幅** | 3種類以上の異なる戦略・シナジー・立ち回りが成立する | 実質的に正解ルートが1つしかない |
| **3. コアループの心地よさ** | 毎ターン/毎秒の基本操作とフィードバック自体が触っていて気持ちいい | 基本操作が単調な作業になっている |
| **4. 時間設定の妥当性** | 想定プレイ時間に対して成長曲線・ゲーム展開の密度がぴったり合っている | 内容に対して冗長すぎる、または浅すぎる |
| **5. モバイルUI適性** | `375〜430px` 縦画面・片手操作で盤面と選択肢が一目で把握できる | 画面が狭すぎて誤操作する・文字が潰れる |
| **6. 実装・分割開発の実現性** | M1〜M5のマイルストーンに綺麗に分割でき、段階的に検証・構築できる | 全部作らないと動くか分からない密結合設計 |
