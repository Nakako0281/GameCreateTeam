# LocalBox ツール開発ロードマップ (`docs/TOOLS_ROADMAP.md`)

AdSense審査通過と初期90日目標（2027-02-20までに月100円以上）の達成に向けた、全12ツールの開発計画。
すべて **「完全ブラウザ完結・サーバー送信0バイト・非YMYL・AI Overviewsで代替不可」** を基準に選定。

---

## Wave 1: コアMVP 4ツール（実装済み・ローカル確認対象）

1. **AI入力前・個人情報（PII）自動マスキング＆回答復元** (`/tools/ai-pii-masker/`)
   - *狙い*: 生成AI（ChatGPT/Claude/Gemini）を安全に使いたいビジネス層・開発者。Chrome拡張への不信感を突き「ブラウザタブ内で完結＆回答を自動復元」で差別化。
2. **LLMトークン数＆API料金 リアルタイム比較シミュレーター** (`/tools/llm-cost-calculator/`)
   - *狙い*: AI導入検討者・個人開発者・法人担当。日英のトークン効率差・Prompt Caching・Batch割引・円換算まで一発試算。高単価IT広告との相性抜群。
3. **Excel CSV文字化け修復（Shift-JIS ⇔ UTF-8 BOM付）＆列マスキング** (`/tools/csv-encoding-fixer/`)
   - *狙い*: 日本のビジネス現場で毎日発生する「ExcelでCSVが開けない/文字化け」の検索需要＋社外秘列の簡易マスキングをゼロ送信で解決。
4. **画像 EXIF/GPS位置情報 完全削除＆WebP/JPG/PNG一括軽量化** (`/tools/image-exif-cleaner/`)
   - *狙い*: SNS投稿・ブログ・業務資料に写真を載せる前の安全対策。Canvas再描画でメタデータを物理消去＋軽量化を一括実行。

---

## Wave 2: 拡充 4ツール（Phase 1〜2・AI順次実装）

5. **PDF「真の墨消し（黒塗り）」＆メタデータ完全削除** (`/tools/pdf-redactor/`)
   - *狙い*: 黒塗りの下に文字データが残る事故を防ぐため、ローカルでPDFをレンダリング・黒塗り焼付け・再PDF化し、テキスト抽出を物理的に不可能にする。
6. **PDF 完全ローカル結合・分割・ページ並べ替え** (`/tools/pdf-organizer/`)
   - *狙い*: 巨大海外クラウドPDFサイトへ社内文書を上げられないユーザーの受け皿（「PDF 結合 安全 サーバー送信なし」等）。
7. **AI出力（Markdown・表・数式）➔ Word / Excel / Slack 崩れ整形** (`/tools/ai-markdown-formatter/`)
   - *狙い*: ChatGPT等の出力を社内チャットやドキュメントへ貼る際の `**` や表崩れをワンクリック整形。高い日常リピート率。
8. **`.env` / JSON / YAML / ログファイル 秘匿値自動サニタイズ＆相互変換** (`/tools/config-sanitizer/`)
   - *狙い*: エラーログや設定ファイルをAIや同僚へ相談する前に、トークン・パスワード・接続文字列を自動マスキング＆整形。

---

## Wave 3: 毎日使うリピート 4ツール（Phase 2・AdSense申請直前）

9. **日本の営業日・祝日・納期逆算＆和暦/西暦シミュレーター** (`/tools/jp-business-days/`)
   - *狙い*: 2026〜2030年の日本の祝日・土日・カスタム休業日対応の営業日計算。ブックマークされやすい日常需要。
10. **日本語実務向け 正規表現ビジュアルテスター** (`/tools/regex-tester-jp/`)
    - *狙い*: インボイス番号（T+13桁）・法人番号・郵便番号・全角半角・電話番号のプリセット付きローカルテスト環境。
11. **テキスト文字数・全角半角・機種依存文字クレンザー** (`/tools/text-cleaner/`)
    - *狙い*: フォーム入力・CSV取込前の丸数字や異体字・不可視文字（ゼロ幅スペース等）を一覧検出・一括置換。
12. **完全オフライン高機能QRコード生成＆パスワード強度診断** (`/tools/offline-qr-password/`)
    - *狙い*: 社内Wi-Fi接続QRやURL QRを外部送信なしでSVG/PNG生成＋パスワード強度エントロピーローカル試算。

## Wave 4（AdSense合格後）: 英語圏 `/en/` 横展開（高RPMスケール）
- 日本語サイトでAdSense審査に合格した後、`ai-pii-masker`, `llm-cost-calculator`, `image-exif-cleaner`, `pdf-redactor` 等から順次 `/en/tools/...` 版を構築し、`hreflang` と言語別サイトマップを設定してTier 1（米国・英国等）トラフィックによるRPM向上を狙う。
