# TemotoBox ツール開発ロードマップ (`docs/TOOLS_ROADMAP.md`)

AdSense審査通過と初期90日目標（2027-02-20までに月100円以上）の達成に向けた、全12ツールの開発計画。
すべて **「生成AI・社外共有前の下ごしらえに特化した、完全ブラウザ完結・入力データ送信ゼロ・検証可能な実務ワークベンチ」** を軸に選定している（[ADR-004](ADR/ADR-004-brand-temotobox-and-workbench-positioning.md)）。

## 2層ポートフォリオ戦略（入口 × 定着ワークベンチ）
- **第1層（入口ウェッジ）**: 大手総合サイト（ラッコツールズ等）に専用ツールがない **AI前処理・機密提出実務**（`.env`/Secret秘匿、AI PII往復復元、Word/Excel/Slack整形、最新LLM料金試算、PDF真の墨消し）で検索流入を獲得する。
- **第2層（定着・ブックマーク受け皿）**: 日常頻度の高い実務ツール（CSV修復＋列マスク、EXIF削除＋0件再検査、文字クレンザー、オフラインQR/PW、営業日計算等）を同一の安全な作業場へ揃え、将来的にはツール間のワンクリック受け渡しにより「1タブで業務下ごしらえが完結する体験」でブックマーク定着を狙う。

---

## Wave 1: コアMVP 4ツール（実装済み・ローカル確認対象）

1. **AI入力前・個人情報（PII）自動マスキング＆回答復元** (`/tools/ai-pii-masker/`)
   - *狙い*: 生成AI（ChatGPT/Claude/Gemini）を安全に使いたいビジネス層・開発者。Chrome拡張への不信感を突き「ブラウザタブ内で完結＆回答を自動復元」で差別化。
2. **LLMトークン数＆API料金 リアルタイム比較シミュレーター** (`/tools/llm-cost-calculator/`)
   - *狙い*: AI導入検討者・個人開発者・法人担当。日英のトークン効率差・Prompt Caching・Batch割引・円換算まで一発試算。高単価IT広告との相性抜群。
3. **Excel CSV文字化け修復（Shift-JIS ⇔ UTF-8 BOM付）＆列マスキング** (`/tools/csv-encoding-fixer/`)
   - *狙い*: 日本のビジネス現場で毎日発生する「ExcelでCSVが開けない/文字化け」の検索需要＋社外秘列の簡易マスキングをゼロ送信で解決。
4. **画像 EXIF/GPS位置情報 完全削除＆WebP/JPG/PNG一括軽量化** (`/tools/image-exif-cleaner/`)
   - *狙い*: SNS投稿・ブログ・業務資料に写真を載せる前の安全対策。Canvas再描画でメタデータを物理消去＋軽量化を一括実行。

---

## Wave 2: 拡充 4ツール（Phase 1〜2・AI順次実装）

5. **PDF「真の墨消し（黒塗り）」＆メタデータ完全削除** (`/tools/pdf-redactor/`) — **実装済み (2026-11-26)**
   - *狙い*: 黒塗りの下に文字データが残る事故を防ぐため、ローカルでPDFをレンダリング・黒塗り焼付け・再PDF化し、テキスト抽出を物理的に不可能にする。
6. **PDF 完全ローカル結合・分割・ページ並べ替え** (`/tools/pdf-organizer/`) — **実装済み (2026-11-27)**
   - *狙い*: 巨大海外クラウドPDFサイトへ社内文書を上げられないユーザーの受け皿（「PDF 結合 安全 サーバー送信なし」等）。ページ単位の注釈/XMP/不要アクション剥離・ZIP分割出力・偶数ページ回転・A4縦フィット統一を備え、`/tools/pdf-redactor/` と連携。
7. **AI出力（Markdown・表・数式）➔ Word / Excel / Slack 崩れ整形** (`/tools/ai-markdown-formatter/`) — **実装済み (2026-11-22)**
   - *狙い*: ChatGPT等の出力を社内チャットやドキュメントへ貼る際の `**` や表崩れをワンクリック整形。高い日常リピート率。
8. **`.env` / JSON / YAML / ログファイル 秘匿値自動サニタイズ＆相互変換** (`/tools/config-sanitizer/`) — **実装済み (2026-11-22)**
   - *狙い*: エラーログや設定ファイルをAIや同僚へ相談する前に、トークン・パスワード・接続文字列を自動マスキング＆整形。

---

## Wave 3: 定着・日常リピート 4ツール（Phase 2・機密実務差別化優先）

※ 汎用単機能の単純模倣は避け、機密性・日本実務特化が活きる **① 文字クレンザー → ② オフラインQR/強度診断 → ③ 日本営業日計算 → ④ 日本語実務正規表現テスター** の順で優先実装し、ツール間連携UXも整備する。

9. **テキスト文字数・全角半角・機種依存文字クレンザー** (`/tools/text-cleaner/`) — **Wave 3 優先①**
   - *狙い*: フォーム入力・CSV取込・AI投入前の丸数字や異体字・不可視文字（ゼロ幅スペース等）を安全に一覧検出・一括置換。
10. **完全オフライン高機能QRコード生成＆パスワード強度診断** (`/tools/offline-qr-password/`) — **Wave 3 優先②**
    - *狙い*: 社内Wi-Fi接続QRや非公開URL QRを外部送信なしでSVG/PNG生成＋パスワード強度エントロピーローカル試算。
11. **日本の営業日・祝日・納期逆算＆和暦/西暦シミュレーター** (`/tools/jp-business-days/`) — **Wave 3 優先③**
    - *狙い*: 2026〜2030年の日本の祝日・土日・カスタム休業日対応の営業日計算。日本実務でのブックマーク需要。
12. **日本語実務向け 正規表現ビジュアルテスター** (`/tools/regex-tester-jp/`) — **Wave 3 優先④**
    - *狙い*: インボイス番号（T+13桁）・法人番号・郵便番号・全角半角・電話番号の日本実務プリセット付きローカル検証環境。

## Wave 4（AdSense合格後）: 英語圏 `/en/` 横展開（高RPMスケール）
- 日本語サイトでAdSense審査に合格した後、`ai-pii-masker`, `llm-cost-calculator`, `image-exif-cleaner`, `pdf-redactor` 等から順次 `/en/tools/...` 版を構築し、`hreflang` と言語別サイトマップを設定してTier 1（米国・英国等）トラフィックによるRPM向上を狙う。
