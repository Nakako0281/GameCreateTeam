# 失敗・教訓・機械化再発防止台帳 (`docs/POSTMORTEM_AND_LESSONS.md`)

> **絶対原則**: 本台帳に記録した教訓に対し「次回から気をつけます」と書いて終わることを禁止する。必ず **「どの自動チェック（スクリプト / テスト）を追加・強化して再発を物理的に封じたか」** をセットで記録する。
