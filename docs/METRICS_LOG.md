## 自律度KPI（実験評価指標 / Issue #54）

「AIがどこまで自律的に考え、人間介入や手戻りを減らしつつ価値を出せるか」を定量観測するため、週次 `audit-and-evolve` で `npm run ops:autonomy`（`node scripts/ops_github.mjs autonomy-report`）を実行し、以下を記録する。

### 指標定義
- **欠陥・改善の自己発見率**: `found-by:ai / (found-by:ai + found-by:human)`（信頼済み作成者Issueのうち `found-by:*` ラベル付与分を集計）
- **人間作業負荷・待ち時間**: `owner:human` Issue の期間内起票/完了件数、完了までの平均/最大日数、および72時間以上滞留中の件数
- **PR手戻り率**: `(fix系PR + クローズ済み未マージPR) / 期間内作成の信頼済みPR総数`
