# ADR-003: ローンチ前倒し計画（6ツール先行本番公開 ＆ #32分割・初期集客並行化）

- **日付**: 2026-11-23
- **ステータス**: 提案中（Proposed — 最高責任者決裁待ち）
- **関連Issue**: `#58`, `#32`, `#35`, `#33`, `#34`
- **目標期限**: 2027-02-20 までに Google AdSense 収益 **100円/月 以上**（本日時点から残り **89日**）

---

## 1. 背景と課題（12/25公開では間に合わないリスク）

従来のロードマップでは「12ツール全実装（12/5目標） → 独自ドメイン取得・本番公開・AdSense申請（12/25目標） → 2/20 収益判定」としていたが、以下の致命的なボトルネックが存在する。

1. **時間不足（残り57日の壁）**: 12/25公開では、収益判定日（2/20）まで **約57日** しか残らない。この期間に「新規ドメインのGoogleインデックス定着・初期ドメイン評価立ち上がり」「AdSense審査（通常1〜3週間）」「月1,000 PV以上の自然流入獲得」をすべて収める必要がある。
2. **検索評価の待機損失**: Google検索のインデックス登録・ドメイン評価の積み上げは **本番ドメインを公開して Google Search Console (GSC) に登録した日** からしか進まない。AdSense審査自体も「ツール本数が12本揃っているか」より「各ページのコンテンツ品質・法務整備・独自価値」が重視され、現在の6ツールでも品質水準は満たしている。
3. **人間待ちクリティカルパスの停滞（Issue #32）**: Issue #32 が「① テスト環境・友人検証」と「② 本番ドメイン取得・DNS設定」を一括にしており、期限も未設定のため、後続のGSC登録・記事公開・AdSense申請すべてがブロックされている。
4. **初期集客の遅延（Issue #35）**: 公開直後の新ドメインが検索流入ゼロ期（サンドボックス期間）を超えるためのZenn/Qiita/X記事が `priority:p2` のまま後ろ倒しになっている。

---

## 2. 決定（提案する前倒し実行計画）

**「12ツール完成を待ってから公開」を改め、「公開品質を満たした現6ツールで即時本番公開し、GSC評価蓄積と開発（Wave 2残・Wave 3）を並行推進する」** 方針を採用する。

| ステップ | 目標期限 | 実施内容 | 担当 |
| :--- | :--- | :--- | :---: |
| **Step 1: 本番先行公開・GSC登録** | **2026-11-29 まで** | `dev` ➔ `main` リリースPRのマージ、独自ドメイン取得（Cloudflare Registrar推奨）、Cloudflare Pages Custom Domain接続、`SITE_URL` / `PUBLIC_GA_ID` 設定、GSCサイトマップ送信・インデックス登録リクエスト | 人間（操作）＋ AI（PR・設定支援） |
| **Step 2: 初動集客記事の公開** | **本番公開と同日〜1週間以内** | `docs/promotions/` に先行作成した技術記事ドラフト2本をZenn/Qiitaへ投稿＋X告知（公開URL設定）し、初動PVと自然被リンクを獲得 | 人間（コピペ公開）＋ AI（ドラフト3本目作成） |
| **Step 3: 残ツール並行拡充** | **2026-12上旬〜中旬** | Wave 2残2本（`pdf-organizer`, `pdf-redactor`）および Wave 3（4本）を順次 `dev` → `main` へ追加公開（自動デプロイ＆サイトマップ自動反映） | AI |
| **Step 4: AdSense 初回申請** | **2026-12-10 前後** | 公開8〜10ツール到達、またはGSCで検索表示回数（インプレッション）が立ち上がり始めたタイミングでAdSense初回審査を申請（`PUBLIC_ADSENSE_CLIENT` 組込） | 人間（管理画面申請）＋ AI（コード反映） |

## 3. Issue #32 の2トラック分割案

人間側の確認負荷を増やさずクリティカルパスだけ先に通すため、Issue #32 を以下の2トラックへ分割することを提案する。

- **Track A（クリティカルパス・期限目安: 2026-11-29）**:
  - 独自ドメイン取得（Cloudflare Registrar 年約$11.17）→ Cloudflare Pages 紐づけ → `SITE_URL` 設定 → GSC登録＆サイトマップ送信。
  - ※ ドメイン取得・本番公開がそのまま最大のテスト環境にもなり、後からツール追加・UI改善は何度でも無停止デプロイできる。
- **Track B（並行検証・期限目安: 2026-12-06）**:
  - 友人エンジニアおよび本人による追加の実機フィードバック収集。指摘事項は通常通り AI が次スプリントの PR で順次修正・反映する。

---

## 4. トレードオフと撤回・見直し条件

- **トレードオフ**: 6ツール時点（追加予定ツールが「今後追加予定」表示の状態）で本番公開するため、全12ツール同時公開より初日ラインナップは少ない。ただし、すでに公開中の6ツールはいずれも実用・1,200字超ガイド・FAQ・E2E検証を備えており、トップページの「追加予定」表示も誠実なロードマップとして成立している。
- **撤回・見直し条件**: 本番公開後、GSCのインデックス登録が極端に遅れる（公開14日経過後もインデックス2ページ以下）場合は、トップ/ツール間内部リンク構造とXMLサイトマップ再送信・技術記事追加投入を最優先で実施する。
