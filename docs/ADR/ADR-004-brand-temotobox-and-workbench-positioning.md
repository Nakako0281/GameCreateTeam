# ADR-004: ブランド刷新 `TemotoBox`（`temotobox.com`）＆ 機密・AI実務ワークベンチ2層戦略

- **日付**: 2026-11-23
- **ステータス**: 採用（Accepted）
- **決定者**: 人間メンバー（最終責任者）＋ AI組織全5ロール協議合意（`00`, `01`, `02`, `03`, `05`, `06`）
- **関連ADR / Issue**: `ADR-001`, `ADR-002`, `ADR-003`, `#32`, `#33`, `#34`, `#35`

---

## 1. 背景：既存ブランド被りの発覚とラッコツールズ比較からの問い直し

1. **名称・ドメイン調査結果（2026-11-23 実測）**:
   - `localbox.com` / `.dev` / `.app` / `.net` / `getlocalbox.com` はすべて取得済みであり、さらに同種のクライアントサイド開発者ツール集「LocalBox Tools (`bottlespan.com`)」、iOSローカルLLMアプリ `localbox.ai`、Macエージェントサンドボックス `localbox.sh`、Microsoft Jumpstart LocalBox 等がすでに多数存在していた。
   - あわせて `OTEMOTO`（`otemoto.com/.app` 取得済、食品EC・割り箸と重複）および `TabChest`（同名Chrome拡張が実在）も競合調査の結果除外した。
2. **国内最大手（ラッコツールズ `rakko.tools`）との正面比較**:
   - ラッコ株式会社が運営する `rakko.tools` は 130 種類以上のツール・強固なドメインパワー・法人信用力を持ち、さらにクライアント側で完結するツール（Markdownプレビュー・JSON整形・JWT・PDFページ操作等）ではすでに「ブラウザ完結・サーバー送信なし」を明記している。
   - すなわち、**「ブラウザ完結だから勝てる」「何でも揃う総合ツール集として戦う」という前提は幻想**であり、同じ土俵（素の文字数カウント・QRコード・正規表現等の汎用単機能）で正面衝突しても勝てない。
   - 一方で、ラッコツールズには以下の領域・思想が欠けており、ここに明確な生存・成長の軸がある：
     - **生成AI前処理×社外秘提出実務の専用ワークベンチ不在**: AI入力前PII往復マスク＆復元、`.env`/K8s Secret非破壊秘匿化、Word/Excel数式防御TSV/Slack幅揃えMarkdown整形、最新世代LLMの日本円・改定予定単価比較、CSV文字化け＋列マスク、EXIF削除前診断＆0件再検査、PDF真の墨消し（焼付け）。
     - **「企業の善意を信じる」ではなく「自分で検証できる」設計**: ラッコツールズはサーバー処理ツールとブラウザ完結ツールが同一ドメインに混在しソースコードも非公開だが、私たちはサーバー受信口を持たない100%静的構成・ソースコード全公開・広告/解析有効ビルドでのカナリア入力漏洩ゼロE2E（`test:e2e:ads` / L-14）により技術者が自ら監査できる。

## 2. 決定事項

### ① ブランド名・取得ドメインの確定
- **ブランド名（正式表記）**: **`TemotoBox`**（カタカナ副題例：手元のブラウザ道具箱）
- **本番ドメイン**: **`temotobox.com`**（ハイフン無し `.com`、2026-11-23 RDAP 404 未登録確認済み、Cloudflare Registrar 原価 年約 \$11）
- **命名・混同防止ルール（`03` 保安・法務条件）**:
  - 既存の単機能Webツール `temoto.app` や建築積算SaaS「TEMOTO」との混同を防ぐため、サイト内・記事・SNS・問い合わせでは必ずフルネーム **`TemotoBox`** を使い、単体で「TEMOTO」と略さない。
  - ドメインは `temoto-box.com`（ハイフン入り）ではなくハイフン無しの **`temotobox.com`** とする。

### ② プロダクト・ポジショニングの再定義
> **「生成AIや社外共有の前に、機密データ・ファイルを安全に下ごしらえするための、ソース公開・検証可能な『機密実務専用ワークベンチ』」**

差別化の3本柱：
1. **生成AI×機密実務の深い専用ツール群**（ラッコツールズ等の汎用百貨店がカバーしていない「実務の1手間・安全性」特化）。
2. **混在ゼロ × ソース公開 × CI漏洩ゼロ証明による「検証可能性」**（全ページがサーバー送信API非保持、`test:e2e` ＋ `test:e2e:ads` で毎回自動証明）。
3. **固定費 年約 \$11 の機動力と「AI自律運営実験」の一次情報価値**（実測データに基づく即断即改と Zenn/Qiita/X での開発・監査知見共有）。

### ③ 2層ポートフォリオ戦略（入口ウェッジ × 定着ワークベンチ）
競合から逃げてニッチに閉じこもるのではなく、**「尖った入口ツールで新規検索を獲り、定番ツールと連続ワークフローで回遊・ブックマークを育てる2層構造」** を意図的に設計する。

- **第1層（入口・差別化ウェッジ）**: `.env`/K8s Secret秘匿化、AI Markdown整形、最新LLM料金試算、PDF真の墨消し（Wave 2優先）、AI PIIマスカー 等。
- **第2層（定着・ブックマーク受け皿）**: CSV修復、EXIF削除、および Wave 3 ツール群。ただし素の劣化コピーにはせず、**「機密を安心して貼れる実務の一貫体験」** として差別化する：
  - **Wave 3 実装優先順**: ① `text-cleaner`（文字数＋機種依存文字・不可視文字クレンザー）、`offline-qr-password`（社内Wi-FiオフラインQR＆強度診断）、`jp-business-days`（日本祝日・営業日・納期逆算）を先行し、② `regex-tester-jp`（インボイス番号・法人番号等の日本実務プリセット特化）を後続とする。
  - **定着UXの方向性**: 将来的にツール間のワンクリック受け渡し（例：PIIマスク後にそのまま整形・文字クレンザーへ送る等）により「複数サイトを行き来せず1タブで片付くワークベンチ」へ発展させる。

## 3. 公開30日の定量検証・見直し基準

本番公開後30日時点で GSC・GA4 データを計測し、以下を目安にポートフォリオを入れ替え・深掘り判断する：
- GSC クリック数の立ち上がり・ツール別インプレッション傾向
- GA4 ツール実行完了率（目安 40% 以上）・回遊ページ数（目安 1.2 以上）・7日再訪率（目安 10% 以上）
- 反応が薄いツールや検索意図のズレが見えた領域は、伸びている領域（AI前処理・秘匿化・PDF安全処理等）の派生ツール・連携UXへリソースを再配分する。
