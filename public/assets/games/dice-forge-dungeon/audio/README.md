# 🔊 『ダイス・フォージ・ダンジョン』音声素材配置フォルダ (`public/assets/games/dice-forge-dungeon/audio/`)

このフォルダは、人間（最高責任者）がダウンロードした**無料のフリー効果音（SE）・BGM素材**を配置するための専用フォルダです。

---

## 📂 配置するファイル名と対応イベント一覧

以下のファイル名で `.mp3`（または `.ogg` / `.wav`）ファイルをこのフォルダに配置すると、ゲーム側（`src/games/dice-forge-dungeon/audio.ts`）が自動的に読み込んで再生します。

> [!TIP]
> **フォールバック機構について**:
> ファイルがまだ配置されていない場合（または一部のファイルだけ配置した場合）でも、未配置のサウンドは自動的にブラウザ内蔵のWeb Audioシンセ音（フォールバック仮音）で再生されるため、エラーになることはありません。いつでもお好きなタイミングでファイルを追加・差し替えできます。

| ファイル名 | 再生されるタイミング | おすすめのフリー素材のニュアンス |
| :--- | :--- | :--- |
| **`se_dice_roll.mp3`** | ダイスを振る（ロール/リロール）時 | サイコロが複数個コロコロッと転がる音（0.4〜0.8秒程度） |
| **`se_dice_place.mp3`** | ダイスをスロットに配置・操作した時 | 木の駒や石を「カチッ / コトン」と盤面に置く心地よい音 |
| **`se_combo_step.mp3`** | 共鳴役・レリックの乗算リレー時 | 「シャキーン / キラーン」という短いクリスタル音（※連鎖数に応じて自動でピッチが上がります） |
| **`se_attack_slash.mp3`** | ⚔️斬撃スロットの攻撃ヒット時 | 剣で斬りつける鋭い斬撃・打撃音 |
| **`se_guard_shield.mp3`** | 🛡️障壁スロットでシールド獲得時 | 金属の盾を構える「ガキィン！」という重厚な音 |
| **`se_magic_burst.mp3`** | 🔮魔導スロット・毒・マナ介入時 | 魔力が炸裂する「シュゴォン / バチバチッ」という魔法効果音 |
| **`se_forge_hammer.mp3`** | ⚒️鍛造工房でダイス面を彫り直した時 | 鉄床をハンマーで「カンッ！」と叩く鍛冶音 |
| **`se_victory.mp3`** | フロア突破・ボス撃破時 | 短い勝利ジングル・ファンファーレ（2〜4秒程度） |
| **`bgm_dungeon.mp3`** | ダンジョン探索・戦闘中BGM（ループ再生） | 思考を邪魔しないダークファンタジー／ローグライト風BGM |
